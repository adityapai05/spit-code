About Quest

A game discovery website where you describe what you want to play and get real game suggestions.

What is Quest?

Quest is a multi-page website that helps people decide which video game to play next. Instead of scrolling through long lists, the user types a sentence such as "a short emotional story game" or "something like Hollow Knight". Quest turns that sentence into filters, finds matching games from the RAWG game database and explains why each game was suggested.

Users can also browse all games, open a game to see its details and save games to their own library as Want to Play, Playing or Completed.

The problem we wanted to solve

Game stores show thousands of titles, and normal search boxes only work if you already know the name of the game or the exact filters to use. Most people just know how they feel ("something calm", "something scary with friends"). Quest lets them say that directly.

Main features

Recommender (natural language)

The user writes a sentence. Gemini converts it to genres and tags. RAWG returns matching games, each with a "why" line. It works right on the home page.

Browse Games

Search by name and filter by genre, platform, rating and playtime. Sort the list and move between pages.

Game details

Cover image, rating, Metacritic score, platforms, playtime, screenshots, store links and description.

My Library

After login, a user can save any game from its card or details page as Want to Play, Playing or Completed, change the status later or remove it.

Home page sections

Popular, New releases, Top rated and Coming soon, all loaded live from RAWG.

Login and signup

Email and password accounts using Supabase, so every user has a private library.

How the recommender works

1. User sentence"a scary co-op game"
→
2. Geminireturns genres and tags as JSON
→
3. RAWGsearches games with those filters
→
4. Resultsgame cards with a reason

Gemini never invents game names. It is only allowed to choose from a fixed list of genres and tags that RAWG understands, and every game shown comes from RAWG. If the user says "like Hollow Knight", we look that game up in RAWG and reuse its genres and tags. If Gemini is not available, the site falls back to a normal RAWG search with the user's words, so it never breaks.

Database (Supabase)

We use one table called library. Row Level Security is switched on, so a user can only read and change their own rows.

Column Meaning
id Row number
user_id The logged in user who owns the row
game_id The game's id in RAWG
game_name, game_image Saved so the library page can show the game without asking RAWG again
status want-to-play, playing or completed
created_at When the game was added
